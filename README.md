## Objective
Create the Pong game
Players: Artificial Intelligence vs Users

## Controls
- **Arrow Keys**: Up ↑ and Down ↓ arrows to move player paddle
- **Mouse Wheel**: Scroll up/down to move player paddle (faster response)
- **Quit Game**: Press ESC or Q key to exit with confirmation

## How to Play
1. Open `index.html` in any modern web browser
2. Use controls to move your paddle (left side)
3. Try to hit the ball past the AI opponent (right side)
4. First to score wins the point
5. Game continues indefinitely - use quit keys to exit
